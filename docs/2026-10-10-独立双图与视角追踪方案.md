# 独立双图与视角追踪

1. 移除页面内 fixed + CSS resize 浮动面板入口与受页面边界限制的拖动处理。浮动按钮和标题拖动统一打开真正的地图窗口；浏览器未允许弹窗时明确提示使用桌面版，不再退回伪窗口。
2. 桌面地图改为无 parent 的原生顶层 BrowserWindow，保留系统标题栏与四边缩放能力。主窗口关闭时显式清理地图窗口。分别管理探索树、知识图和并看窗口；树与图可同时独立打开，各自吸附、关闭、记忆尺寸。
3. 图面板提供“独立探索树”“独立知识图”入口。已独立的图在工作台显示返回入口，不重复渲染；独立单图窗口固定显示其图，不被另一个窗口的标签切换影响。同一图同时只存在一个浮动实例。
4. 主窗口为会话状态权威；各地图共享选中事件/模块、关系显示模式和设置，同步消息携带窗口标识并定向处理，避免一个窗口关闭影响另一个窗口。浏览器弹窗保留同等双图同步能力。
5. 增加持久化的“视角追踪”设置，默认开启，地图内可直接开关。关闭后仍显示关联高亮，但另一张图不再因关联选择自动平移或缩放；用户在本图直接选择、分类筛选及手动适应全图仍正常。打开追踪时立即聚焦关联节点。
6. 验证两窗口同时打开与独立关闭/吸附、四边缩放、移出主窗口、主窗口移动不牵动地图、显示模式同步及追踪开关前后的视角行为。构建桌面应用并保存验收记录，按创作纪律提交。

参考：[Electron 顶层与父子窗口](https://www.electronjs.org/docs/latest/api/browser-window#parent-and-child-windows)。用户描述的边界限制与 CSS 浮动面板实现相符；最终以真实窗口实操验证，不将 API 声明等同于用户交互验证。

## 验收结果

- 删除受页面边界限制的浮动状态与 CSS resize 面板，统一真实窗口入口。标题栏拖出当前视图、单图按钮、独立窗口吸附均已接通。
- 桌面窗口不设 parent，两张单图可同时存在；原生标题栏及窗口四边负责移动和缩放。主窗口仍显式管理退出清理；进入并看窗口时收回两个单图实例，避免重复编辑。
- 45 项前端测试、3 项桌面窗口规则测试通过，严格类型检查及生产构建通过。测试覆盖窗口组合冲突、旧 URL 兼容、默认追踪与关闭偏好的恢复。
- 11 项原生冒烟检查通过：两窗口并存、顶层属性、窗口完全位于工作台外仍可见、移动工作台不改变地图位置、四边边界修改、独立吸附保留另一窗口等。程序化边界检查之外，使用 Computer Use 实际拖动四条边验证截图尺寸变化（单位为截图像素）：右 1280→1400，左 1400→1340，上 1280→1240，下 1240→1340；证据保存在 `frontend-preview/independent-resize-checks.json`。
- 桌面实操：独立树窗口通过鼠标标题栏拖出工作台后仍正常显示；同时打开知识图，工作台识别两个独立实例；从知识图关闭追踪后，工作台及树窗口均显示关闭；单独吸附树后知识图仍存在，关闭知识图后工作台恢复两图。
- 浏览器实操：关闭追踪，知识图选择“向量与空间”后树图的 viewport transform 完全不变，仍有 2 个关联高亮；树选择“发现不变的方向”后知识图 transform 完全不变，仍有 1 个关联高亮。开启追踪后树视角实际改变，聚焦关联节点。完成后恢复开启。
