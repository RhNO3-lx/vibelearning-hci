# 浮动地图与事件节点修订

1. 连线使用自定义直线边：取两个实际测量矩形的中心，以中心连线与各矩形边界的交点为起终点。拖动节点、改变大小时自动重算，箭头不穿入框内。
2. 改进应用内浮动面板，允许移动、调整尺寸、拖到右侧吸附；提供浏览器独立窗口入口，通过地图专用页面与 BroadcastChannel 同步状态。主工作台保存权威状态，独立页面发送操作。浏览器不支持独立窗口时保留应用内浮动功能，暂不引入桌面打包依赖。
3. 知识图使用青色；知识图选择时，以关联的本会话所有事件作为探索树视野目标，修复单向缓动。
4. 叶子事件节点右键提供“设为主线终点”。主线紫色实线，去掉旗子图标；状态层拒绝把非叶子节点设为终点。
5. 原先修关系迁移为推荐学习顺序。支持增添、反转、移除推荐边，已有会话路线继续可排序。同步更新共享数据契约，保持节点难度属性。
6. 事件节点只呈现左侧分类图标、右侧每行六字且最多两行的短标题；完整信息保留在提示与详情中。右侧类别卡片显示概念讲解、集中检测、实操演练、闪卡回顾；点击可高亮并聚焦所有匹配事件，再点取消。
7. 验证中心连线几何（不同方位、尺寸、重叠）、旧关系迁移、推荐顺序编辑、叶子终点保护，以及浏览器双向联动、右键、类别筛选、浮动及吸附。

## 验收记录

- 35 项测试通过，涵盖六种方位与不同尺寸的边界交点、共线性、重叠处理、六字两行标题、旧先修边迁移、推荐增删与反转、非叶子终点保护。TypeScript 与生产构建通过。
- SVG 连线实际路径为 `M … L …`，节点拖动或尺寸变化时根据测量框重算交点；图标与短标题取代原事件卡片的元信息堆叠，旗子已移除。
- 选择知识模块“向量与空间”后，上图“从直觉走向证明”和“理解线性变换”均青色外发光，缓动后完全位于探索树画布内。反向选择事件时，下图继续紫色外发光并聚焦全部关联模块。下图选中主色为青色。
- 类别卡片“概念讲解”点击后，当前会话 5 个事件均高亮；再次点击取消。右键非叶子事件的终点操作禁用，右键叶子事件可切换紫色实线主线，测试后恢复原终点。
- 推荐编辑器实际验证反转与恢复、添加临时推荐及移除，已有用户关系和路线保留。
- 浮动面板由 440×740 实际拖小到 360×660，拖至右侧成功吸附。修正标题拖动时产生页面文字选区的问题。
- 独立地图页面只显示地图；在独立页面选择事件，主工作台同步切换对话位置；吸附按钮恢复主工作台地图。状态写入由主工作台负责，独立页面通过 BroadcastChannel 发送操作。
- 独立入口使用浏览器窗口 API 请求 540×780 可调整窗口；是否成为操作系统窗口或新标签页由浏览器宿主决定。已验证专用页面、同步与吸附，未打包桌面应用、未声明控制系统级置顶。
