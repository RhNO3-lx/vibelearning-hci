# 前端阶段验收记录

日期：2026-10-10。交付：code/frontend 中独立可运行的 React 前端。范围是完整前端交互原型，真实 Agent、知识推断与沙盒仍属于后端阶段。

## 需求覆盖

| 项目构想中的前端要求 | 本轮实现 |
|---|---|
| 线性对话、上下文占用、图片附件 | 祖先路径对话、旧轮展开、文本 token 估算、文件选择/拖放/粘贴和运行期预览 |
| 知识库、子 Agent、技能、工作区 | 独立配置页、会话绑定、启停、同一会话共享工作区路径；真实调用明确待接入 |
| 划词分叉、答题卡与闪卡 | 选中文本后追问；单选反馈、闪卡翻面/自评、项目清单 |
| 探索图的节点、增删、切换、主线 | 一轮问答一节点；新分支；删除子树；选择历史节点；唯一主线路径；活动/知识关联 |
| 子树摘要 | 演示摘要及版本；按分支接收；幂等、替代旧版本与撤回；生产摘要生成/检索后置 |
| 知识图与节点属性 | 全局模块、知识点展开、参考分/证据不足、难点、概要、难度、来源、关联对话 |
| 边的属性 | 区分先修/有帮助；详情显示置信度、帮助说明和依据；未知置信度不填伪数值 |
| 诊断分支与学习路径编辑 | 当前节点下发起诊断；增删/排序；移出原因；路线咨询形成孩子节点 |
| 两图交叉高亮、浮窗与吸附 | 选中对话关联知识；知识关联对话；单图/并看；拖动、缩放、浮动和右侧吸附 |
| 操作流程可测试 | 两个初始会话、有限领域示例、未知目标引导、本地保存/导出、桌面与窄屏 |

## 自动检查

- `npm run build`：TypeScript 严格检查和 Vite 生产构建。
- `npm test`：19 项测试，包含分叉祖先链、重复摘要版本、版本替代、跨会话父节点拒绝、主线、删除与撤回、异步回复不抢占其他会话、测验幂等、闪卡自评不计分、路线范围、全局删除保留历史、损坏状态和树循环拒绝。
- `npm audit`：当前依赖无已知漏洞；KaTeX 更新并统一传递依赖版本。
- Prettier 格式检查与 Git whitespace 检查。

## 浏览器实际验证

使用 Browser 技能在 Codex 内浏览器测试本地服务，未使用真实用户资料或密钥。

1. 1280×720 首屏：三栏、数学排版、输入区固定；探索图默认聚焦当前分支，缩放后可查看全图。
2. 从知识模块发起诊断，提交选项后显示反馈及一条演示证据。
3. 路线排序、移出、选择“已学过”原因、重新加入。
4. 地图浮动后拖动到右边缘，恢复吸附。
5. 划选“新的坐标基”，分叉输入带原文；发送后刷新仍保留新节点。
6. Agent 编辑保存、技能启用、资料登记及会话能力选择。
7. 新会话目标与工作区引导；图片剪贴板粘贴、发送；刷新后保留元数据并提示预览重新添加。
8. 两图并看与知识→对话高亮；展开知识点。已修复并看容器尺寸变化时视口不重新聚焦的问题。
9. 390×844 窄屏：对话、侧栏、设置表单、地图收起；DOM 横向宽度等于视口宽度，无横向溢出。
10. 浏览器日志无应用运行错误；最终生产预览独立检查。
