# 双关系图与桌面窗口

1. 将知识边区分为全局先修关系、按会话保存的推荐关系。会话图取学习路线及本会话对话涉及的有效模块，排除其他会话的独立模块。
2. 推荐子图保持弱连通：按当前路线顺序为不连通分量补最少连接；新节点、模块删除和旧数据迁移均修复缺口。删除会造成断开的推荐桥边时，提示先补替代连接。反转推荐不改变弱连通性。先修边不参与推荐图连通性判定，不能用先修边掩盖推荐缺口。
3. 窗口内增加关系卡片，可切换先修、推荐、同时显示；关系编辑支持新增先修与推荐、反转、移除，先修关系禁止形成环。同向双关系合并标注，避免箭头完全重叠。
4. 增加 Electron 桌面壳和可运行 macOS 应用。主窗口和非模态地图子窗口采用原生标题栏、标准最小化/缩放控制、可调整边框；通过受限 IPC 管理打开、关闭、吸附，通过同源状态通道共享会话状态。保留浏览器版，但不再以浏览器弹出页冒充原生窗口。
5. 原生子窗口关闭、吸附、父窗口退出都有确定的生命周期处理；恢复窗口尺寸，提供吸附按钮，并支持移入父窗口右侧吸附区域。
6. 验证会话范围、连通修复、双关系迁移、桥边保护、先修无环和模式显示；生产构建、原生窗口生命周期检查及桌面实操。使用 Computer Use 技能检查真实桌面窗口。
7. 按追加要求，活动数量为零的类别卡片置灰并禁用，悬停显示“该类别没有活动”；当前筛选类别的最后一个事件被移除时，退出该筛选，避免视角跳向空图。

参考：[Electron BrowserWindow](https://www.electronjs.org/docs/latest/api/browser-window/)、[自定义协议](https://www.electronjs.org/docs/latest/api/protocol)、[安全配置](https://www.electronjs.org/docs/latest/tutorial/security)。

## 完成与验收

- 会话知识图取路线与会话事件涉及的有效模块；两个会话独立维护推荐关系。连通检查只计算推荐边，新增/删除模块、旧数据恢复时按路线为分量补最少连接；桥边删除要求先添加替代连接。
- 全局先修关系保留，新增和反转都检查环。右侧卡片切换三种模式；同方向的双关系合并为“先修 · 推荐”标注，避免完全重叠。
- 空类别卡片置灰、禁用，并由卡片容器显示准确的悬停提示。实际点击零活动“集中检测”卡片后，React Flow 视角变换前后完全相同；存在活动的类别仍可选择。
- 42 项 Vitest 测试通过，严格类型检查及生产构建通过。新增验证覆盖会话隔离、最少连通修复、桥边保护、节点增删、先修环检测和旧数据迁移。
- 2 项原生窗口规则测试通过；Electron 冒烟实际创建窗口并通过 9 项检查：本地页面加载、父子关系、可调整、可缩放、实际尺寸修改、最小化恢复、吸附销毁、恢复上次尺寸、关闭子窗口。
- 使用 Computer Use 实操最终 macOS 应用：从父窗口进入“并看 / 同时显示”，打开原生地图子窗口，执行系统窗口缩放、适应全图、通过界面吸附回父窗口。显示模式保持，父窗口地图恢复。默认宽度下的类别名称和数量保留。
