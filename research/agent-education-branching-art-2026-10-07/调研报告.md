# 教育 Agent 的分支追问、实时打断与艺术教学

检索截止：2026-10-07。这是有范围的专题调研，不是穷尽系统综述。逐篇阅读深度见 `papers/catalog.csv` 和 `papers/notes/`。标为“未下载”的条目只依据原始摘要、机构索引或明确列出的相邻论文介绍，不能当作已核查全文。

## 先回答三个问题

1. **有人研究树状/非线性 LLM 交互，也有人研究上下文分支隔离；但本轮没有找到把教育 session 树、分支作用域记忆、自由追问与主线恢复一起操纵，并测量真人无AI学习效果的直接研究。** 这是有限检索结论，不是“世界上无人做过”。最接近技术机制的是 ContextBranch；最接近真实使用体验的是 CanvasConvo；学习者主动权的教育研究则早已存在。
2. **实时插话并非新机制，处理方式与体验有关；但教育文本 Agent 的“输出截断/工具 abort 是否改善学习”仍缺直接实证。** 语音研究是邻近证据，不能完整迁移到键盘输入、流式文本和有副作用的工具执行。
3. **艺术领域已有课堂教学代理、绘画支架和音频反馈系统；严格的自主、多工具、长期记忆 Agent 的独立技能因果证据还较薄。** 多数研究采用准实验、作品评分、问卷和访谈，常见缺口是撤去AI后的保持与迁移。

## 一、你的“树”包含几种不同机制

| 层面 | 具体含义 | 应证明什么 |
|---|---|---|
| 对话表示 | 把消息/session画成树，允许回看与分叉 | 学习者更容易定位、切换、恢复，是否理解继承关系 |
| 输入上下文 | 每次调用仅带祖先路径、当前分支及必要摘要 | 主线约束是否保留；相邻分支信息是否错误泄漏 |
| 学习者记忆 | 长期保存已知、误解、作品、练习证据 | 个性化诊断是否准确，分支中的有效学习证据是否被遗忘 |
| 教学调度 | 当前目标、先修补救、开放探索及回主线 | 既能追问又能完成目标；回归是否过于强制 |
| 执行控制 | 停止流式输出、取消工具、处理已经提交的结果 | 停得及时、后续状态一致、能回应新意图 |

**仅显示树，不会自动隔离模型上下文；把记忆全部隔离，也可能丢掉支线中发现的关键误解。** 你的假设应该包含“学习者如何理解并信任上下文边界”。线性UI也可在后台做话题分段和范围检索，因此对照不能把“线性”默认设为一定混乱。

可采用的工程思路（以下是研究设计建议，不是已验证教学策略）：主线保存学习目标与完成证据；每个分支有局部上下文；跨分支只提升有来源的知识/误解证据；用户能看到哪些内容会返回主线。长期知识关系可能需要图或DAG，session导航可以继续是树。

## 二、实时打断：有体验证据，学习效应仍应实验验证

区分：学习者在轮次之间追问；学习者在输出过程中抢占控制；外部通知打断学习者；Agent主动打断学习者。这四者的因果方向不同。这里聚焦前两种。

| 论文 | 实际证据 | 能否回答你的问题 |
|---|---|---|
| I01 [Designing the Impression of Social Agents’ Real-time Interruption Handling](https://www.dfki.de/fileadmin/user_upload/import/10535_ivaea493.pdf)，IVA 2019 | 机构PDF搜索索引显示42人被试内三种时序；延迟停止与较高主导性、较少亲近有关；友好总体检验仅边缘显著 | 接近“停止延迟改变体验”；PDF下载403，需进一步全文核实。没有学习测验 |
| I05 [Interruption Handling for Conversational Robots](https://arxiv.org/abs/2501.01568)，RSS 2025 | 21人，决策与讨论任务；意图分类后选择回应/继续/让出话轮。处理失败与较低被重视感、满意度相关 | 有真人体验证据，但为探索性相关；无随机“可打断 vs 不可打断”教育对照。93.69%为排除部分异常后的104/111 |
| I02 [Handling User Interruptions in an Embodied Conversational Agent](https://www.cs.ox.ac.uk/publications/publication3549-abstract.html)，2010 | 继续、重规划、abort的早期机制 | 说明“停止后怎么接续”已有系统设计历史；非学习因果效果 |
| I06 [InterruptBench](https://arxiv.org/abs/2604.00892)，2026预印本 | 有工具Web Agent中途增加、修改、撤回要求；测成功与恢复效率 | 最贴近执行状态问题，但属于模拟技术基准 |
| I03 [Turn-Taking Cues in a Human Tutoring Corpus](https://aclanthology.org/P11-3017/)，2011；I07 [Peer-Learning Dialogue](https://aclanthology.org/W18-5013/)，2018 | 教育语料中的轮次、grounding和呈现策略 | 是教育近邻，未隔离文本输出取消机制的学习效应 |

I04 [Real-Time Reactive Speech Synthesis](https://www.isca-archive.org/interspeech_2017/wester17_interspeech.html)补充语音输出层的增量处理。

文本Agent中，“已输入”“已发送”“停止呈现”“取消模型生成”“取消工具执行”是不同事件。明确用户以发送或停止键表达打断后，记录以下时刻：请求、停止呈现、停止生成、取消请求发出、工具确认、回应新问题、恢复原目标。已完成的副作用不能因abort就视为撤销。

**设计假设：** 实时控制可能减少等待和挫败、提升掌控感；也可能导致解释不完整、频繁切换和遗漏。用“澄清/纠错/跳过已懂内容/换目标/取消执行”等意图编码，比只计打断次数有价值。文本显式发送与语音backchannel应分开。

## 三、艺术教育做到了什么

这里以视觉艺术/设计为主，补充音乐。艺术史知识、视觉鉴赏、构图设计、手绘动作技能、数字工具能力及AI素养应分开；艺术设计课程中出现Agent不等于证明其能教所有艺术技能。

| 论文 | 场景与方法 | 有效策略与局限 |
|---|---|---|
| A02 [GenAI in Art Education系统综述](https://doi.org/10.3390/educsci16010047)，2026卷 | 19项实证，检索截至2025年8月；多为高教/东亚和混合方法 | 把生成工具放进明确教学活动、反馈和反思。总结早期趋势，非自主Agent元分析 |
| A03 [Chen等：设计艺术课程教学代理](https://doi.org/10.1080/14703297.2025.2503857)，2025 | 64名本科生；ChatGPT教学代理 vs 传统多媒体，准实验；成就、动机、自我效能 | 最直接的课程Agent近邻，偏设计史知识；本轮只核查原始摘要及综述表，未获全文 |
| A01 [SakugaFlow](https://arxiv.org/abs/2506.08443)，2025预印本 | 四阶段插画生成、LLM指导、局部修改和版本分支 | 系统构想非常接近；没有受控技能实验。分支的是作品版本，不能说已研究session记忆树 |
| A04 [DrawMyPhoto](https://doi.org/10.1145/3325480.3325507)，C&C 2019 | 20人、两组；分步图像指导及力度/倾斜反馈；专家盲评作品、问卷访谈、日志 | 方法可借鉴；传统绘画辅导工具，非LLM Agent。原始PDF索引核查，下载未成功 |
| A06 [Bian等](https://www.nature.com/articles/s41599-025-05860-2)，2025 | 78名五年级学生，AI示例图 vs 经典图；投入、自我效能、负荷与作品评分 | 教师筛选和匹配示例；不是Agent对话机制。单校短期研究 |
| A07 [结构化设计思维+GAI](https://doi.org/10.3389/fpsyg.2026.1847432)，2026 | 120名动画本科生、4周、3条件；作品匿名随机顺序评分、创意自我效能、PSI | 双钻石流程、阶段反思；作品含AI输出，PSI测感知问题解决。不能直接证明独立技能 |
| A08 [Negotiating creator identity](https://link.springer.com/article/10.1007/s00146-026-03187-3)，2026 | 韩国艺术高中84人、9次周课；前后问卷、观察、反思、28人焦点访谈 | 研究作者身份、控制与伦理协商。无对照；AI技能自我效能非客观技能 |
| A05 [LLaQo](https://arxiv.org/abs/2409.08795)，2024 | 音频语言反馈、教师评分预测；20名音乐学生/教师评价回答 | 领域音频理解比纯文本重要；评价反馈质量，未验证长期演奏进步 |

**常用研究手段：** 形成性访谈与教师共设计；课堂准实验/前后测；专家rubric评分；自我效能、投入、认知负荷量表；过程日志、屏幕录像、作品版本；反思日志与主题分析。长期、无辅助迁移、跨教师跨学校验证较少。

**可转成Agent策略的方向（综合文献后的设计推论）：**

- 把反馈定位到作品区域、音频片段或操作步骤，并说明对应原理；先诊断少数关键问题，再提供可执行练习。
- 用“做一版—解释选择—比较另一版—修改—总结”的循环连接创作和理解；逐步减少提示。
- 保留发散探索，再支持收敛决策；不要让Agent自动把所有分支合成唯一所谓正确风格。
- 把原理/技术纠错与开放审美判断区分，让学生申明创作意图与接受/拒绝建议的理由。
- 对象是手绘或演奏时，必须观察学生自己做的过程，生成的中间图与漂亮成品不足以替代身体练习。
- 教师参与文化语境、个性表达和评价标准；用多样性/作者自主权指标检查对某种风格的过度收敛。

## 四、“行业会要求哪些变量”应如何理解

本轮没有发现一个适用于所有教育Agent研究的统一强制清单。**自变量是操纵/分组，因变量是结果；量表是测量工具；协变量、过程指标和中介各有不同角色。** 学术投稿看证据能否支持声明，产品评估还会关注成本和部署；不能把产品留存替代知识保持。

研究参考：E03 [Unifying AI Tutor Evaluation](https://aclanthology.org/2025.naacl-long.57/)提供8维教学回答评估；E02 [Deng等元分析](https://doi.org/10.1016/j.compedu.2024.105224)强调客观能力、长期跟踪和功效分析；E01 [SRL综述](https://doi.org/10.1007/s10639-024-12881-y)说明过程调节与学习结果需要分别测量。

| 角色 | 推荐变量 | 操作定义/测量 |
|---|---|---|
| 自变量 | 上下文组织 | 全局线性历史 / 分支作用域；固定模型与教学策略 |
| 自变量 | 可视表示 | 聊天列表 / 树状导航；与后台记忆分开操纵 |
| 自变量 | 打断策略 | 发送立即停止并回应 / 排队直到当前输出结束；均允许追问 |
| 自变量 | 恢复策略 | 原目标检查点 / 回归摘要或提示；首轮不同时改变全部功能 |
| 自变量 | 艺术教学策略 | 原理解释/局部反馈/自主比较/结构化反思等，选一个机制 |
| 主要因变量 | 学习效果 | 无AI即时后测、延迟保持、不同材料/题目的迁移；前测调整 |
| 主要因变量 | 体验 | 自主权、被听见感、满意度、挫败；已有量表或明确标为探索性自编 |
| 次要因变量 | 艺术技能 | 新主题无AI创作；结构、明暗/构图、表达等分维度；盲评多评分者 |
| 次要因变量 | 创造性与作者身份 | 专家独立判断新颖/适切，创意自我效能、所有权、自主决策；成品与过程分开 |
| 过程/潜在中介 | 追问行为 | 自发提出率、深度、与目标关系、诊断误解、获得回应；人工编码抽样双评 |
| 过程/潜在中介 | 切换与回归 | 分支深度、回主线率、恢复耗时、用户重述约束次数、未完成目标 |
| 过程/潜在中介 | 上下文管理负担 | “担心影响主线”“花精力维护上下文”的探索性条目＋日志/回溯访谈；不可假称已验证量表 |
| 过程 | 自我调节 | 计划、监控、反思行为与合适SRL子量表 |
| 技术结果/操纵检查 | Agent状态质量 | 主线约束保留、分支泄漏、被误写入长期记忆、工具状态一致性；受控脚本测试 |
| 技术结果/操纵检查 | 打断响应 | 停止延迟p50/p95、重复请求率、取消成功、错误恢复、未完成解释遗漏 |
| 协变量/调节 | 学习者 | 前知识/前技能、AI熟练度、提问习惯、数字素养、动机；事先限定 |
| 控制因素 | 实施条件 | 模型/版本、提示、答案策略、材料难度、时间/练习机会、延迟、教师和设备 |
| 部署指标 | 产品使用与成本 | 复用/流失、每次反馈费用、故障率、教师工作量；只用于对应产品声明 |

量表选择：可用 [NASA-TLX](https://www.nasa.gov/human-systems-integration-division/nasa-task-load-index-tlx/)测交互工作负荷，但它不是教育认知负荷三分量表；用 [MSLQ原手册](https://eric.ed.gov/?id=ED338122)的合适子量表测大学课程动机/策略，儿童、短任务及改写版需另验证。SUS测系统可用性，也不能代替学习。创作rubric与创造性专家独立评价用途不同，应分别报告评分者一致性。

E05 [PNAS无护栏AI实验](https://doi.org/10.1073/pnas.2422633122)给出关键反例：带工具练习表现可提升，而撤去工具后的表现可下降。E06 [AI辅导课堂RCT](https://doi.org/10.1038/s41598-025-97652-6)、E07 [Tutor CoPilot](https://arxiv.org/abs/2410.03017)可作研究方法参照，不能将整体系统效果归因单独分支机制。E08 [ICAP](https://doi.org/10.1080/00461520.2014.965823)提醒我们区分操作行为与建构/互动认知参与。

## 五、建议先做什么实验

### 实验A：分支上下文和可视树的作用

资源允许时采用 **2×2：表示（线性/树状）×上下文（全局/分支范围）**。在四组中都允许自由追问，都提供同样的主线目标与跳转能力；“线性+范围上下文”可以用支线列表/标签实现。固定回答策略、模型、检索材料和练习机会。这样能分开“看起来有结构”和“后台确实隔离”的效应；先做可用性pilot，确认四种组合都自然可用。

若样本不足，先固定同一种UI，只比较后台全局/范围上下文，承认只能回答上下文作用域问题。另用小规模形成性研究选择树的交互方式，不在一个小样本里同时塞入多种机制。

推荐任务：目标是掌握透视/光照中的一个具体原理；提供可自由追问的先修知识和替代画法；所有人最后完成同一主线练习。区分任务相关澄清、必要先修、审美发散和无关岔题，不能把所有追问都设计为垃圾污染。

主要结果：无AI迁移、延迟保持；关键体验结果：自主权与上下文管理负担。过程：问题质量、回主线成本、解释内容的学生复述。先技术测试确认隔离确实改变上下文但没有故意削弱线性组。

### 实验B：实时打断的独立作用

先在同一上下文/UI条件下比较“发送即停并回应”与“问题排队、当前回答完再回应”。两组均能在输出时输入问题，并始终提供明确的紧急停止。固定输出长度策略与响应风格。以明确发送事件作为触发，避免边输入边自动abort带来额外混杂。

先测体验和任务恢复，再验证学习。自由打断者与从未打断者不是随机组；实际打断次数是干预后的行为，不能直接当作自变量进行因果解释。记录实际学习内容暴露与等待时间；它们可能是机制的一部分，不应随意在主效应模型里“控制掉”。

如需研究工具abort，单独加一个可撤销的工具任务，例如生成演示草图或检索示例，明确完成、取消和失败的状态。只停止文本没有验证工具状态恢复，不能宣称“可中断Agent”整体可靠。

### 方法约束

- 学习比较优先随机分组；经验差异较大时按前测分层。被试内体验测试应使用等难题目和顺序平衡，警惕学习携带。
- 用盲评分、清晰rubric和评分者一致性；Agent自己的评分不能作为唯一学习结果。
- 预先声明少数主要结果，报告效应量与置信区间，不只看p值。功效分析依据最小有意义效果、pilot方差、重复测量/班级聚类和流失；没有“通用必须N=30”。
- 用ANCOVA/混合模型处理前测与学生、题目、班级重复结构。日志消息不是独立受试者；缺失与流失需记录。
- 追问更多可能是更敢问，也可能是Agent解释更差；需结合内容编码和后测解释。中介链需要时间顺序和额外假设，先当探索性机制分析。
- 探索型艺术任务里可能出现“更满意，但目标学习变差”的结果；应如实报告这种权衡。

值得优先验证的具体假设是：**可见、可信的分支作用域降低追问抑制，且检查点帮助学习者回到目标；这项收益是否超过分支导航和切换成本？** 该表述比“树状比线性好”更可检验。
