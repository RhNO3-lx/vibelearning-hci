# 可执行研究方案（设计建议，不是已完成实验）

## A. 分支探索与主线恢复：首选HCI方向

**RQ1**：树状界面是否降低探索组织负担？**RQ2**：显式分支任务状态是否减少模型遗漏原目标？**RQ3**：有证据的回归检查是否改善延迟迁移，代价是多少中断与自主性损失？

### 原型范围

领域：DSA的图遍历和最短路。先修：队列/栈、循环不变量、图表示。目标：解释算法、预测行为、实现、调试、在新图与约束下迁移。

固定教学材料、题库、互动模拟、模型版本和提示原则。用户允许提出自己的分支问题。每个分支保存进入时的原目标、暂停步骤、分支目的、未验证点、返回位置。结束时合并概念相关的学习证据，不把完整分支对话强行塞回主线。

### 比较条件

先做2×2：

| 条件 | 界面 | 模型上下文/状态 |
|---|---|---|
| C1 | 线性 | 标准完整历史或现有摘要 |
| C2 | 树状 | 与C1相同 |
| C3 | 线性 | 显式分支状态和按任务检索 |
| C4 | 树状 | 与C3相同 |

界面因素不能同时改变模型输入；记忆因素不能同时改变模型、知识来源、答案难度和提示权限。C3可通过轻量“另开话题/返回”控件表达分支，不显示全树。条件间保持可用能力一致，预先说明这种操作差异。

下一阶段单独比较返回策略：普通摘要 vs. 一道对应原目标的预测/解释检查。保留“继续探索”“暂不返回”选择，并记录原因。若预算不足，先固定界面只比较记忆机制，避免低功效四组实验。

### 测量与设计

主结果：预注册的7天后无AI概念迁移测验。即时测验、21天后保持作为次要或探索指标；所有时长均是方案建议，不是已有证据最佳值。测验用未见题，不能直接重复训练题。

过程指标：返回后完成原任务所需时间、原目标遗漏率、主动中断接受/跳过、不同分支目的、认知负荷、自主感、代码解释与实现的一致性。分支次数不能简单当成越多越好。

先做8—12人形成性研究，再做可用性pilot。正式样本量由pilot方差、预期最小有意义效应和设计效应做功效分析，不给“30人足够发表”的保证。不同教学条件可能有学习迁移，正式实验优先组间随机；任务主题可平衡。基线水平用于分层随机及预注册协变量。评分者盲于条件，抽样双人评分与一致性报告。

分析：主要分析intention-to-treat；报告退出、延迟测试缺失及敏感性分析。题目和学生重复观测采用适当混合效应模型，不能把每个对话轮当成独立学生扩大样本。2×2需预注册交互项与主要对比，避免只有显著子组被报告。

**反证/失败标准**：仅满意度提高而迁移无收益；树状组织时间吞掉学习时间；主线恢复更快但开放探索减少；记忆条件不比完整历史好。应保留并报告这些结果。

## B. 主动误解诊断：首选教学策略方向

依据：SCALA（P03）、ScaffoldLM（P02）、脚手架接纳研究（P09）、适应性提示路由（P08）。

假设：基于矛盾证据与不确定性的诊断，比被动答疑和固定每N轮检查，在同等任务与时间约束下更有效。

三条件：仅学生请求时检查；固定时机检查；基于证据检查。都采用同一问题库、同一最高提示强度和相近学习时间。固定检查的N值需pilot；事件策略阈值也在正式实验前冻结，不能现场调到最优。

触发线索：学生解释与代码行为矛盾、同类错误重复、关键先修未证实、自信/表现不匹配。沉默时长只能作为可能线索，不能直接视为不理解。动作包含不介入、短预测题、反例、换表征、建议暂停。

指标：诊断准确性、错误定位、误报打扰、漏报、下一独立题和延迟迁移；记录学生是否接纳。策略效用可概念化为“预期学习收益 + 信息收益 − 中断/时间成本”，初版用可解释规则，不必先训练RL。

会话外复习提醒应另做纵向研究。有足够数据后可用微随机试验在可提醒时机随机提醒/不提醒，定义短期回归与后续掌握指标并处理重复测量。不能把通知点击率当作学习收益；内容排序与发送时机分开估计。

## C. 提示依赖的学习者记忆：首选AIED/EDM方向

依据：TASA（P12）、CoLearn（P04）、LongTutor（P05）、传统KT（P44—45）。

核心问题：一个学生自己答对，另一个在得到伪代码后答对，系统如何更新掌握信念？已纠正误解在新任务重现如何处理？

比较：无长期记忆；完整历史；LLM自由摘要；事件账本加结构化状态；可选BKT/AKT。所有方法用相同证据、模型和检索预算；完整历史也报告不受同等token限制的强基线，分别讨论预算约束和信息上限。

离线任务：检索正确历史、标记矛盾、预测下一无提示题、选择下一诊断题。加入消融：去提示级别、去时间、去来源、去反证。LLM judge只评教学回复，掌握诊断尽量依据真人独立测验。

指标：AUC之外报告Brier score、校准误差、早期误差、不同能力组的错误、记忆成本与延迟。校准更好不自动意味着教学更好；下一步用同样任务时间的自适应选题实验验证。

事件建议字段：

```json
{
  "learner_id": "pseudonymous-id",
  "event_id": "event-001",
  "concept_ids": ["bfs", "queue"],
  "task_id": "task-03",
  "branch_id": "branch-02",
  "observed_at": "ISO-8601",
  "response_artifact": "answer-or-code-reference",
  "test_outcome": "partial",
  "hint_level": 2,
  "answer_exposed": false,
  "independent_attempt": false,
  "misconception_hypotheses": ["visited-on-dequeue"],
  "evidence_source": "execution-and-explanation",
  "confidence": 0.6,
  "supersedes": null
}
```

误解假设不必当作真值；记录教师/人工复核。用户纠正或要求删除时，来源事件与派生摘要需一致更新。学习研究需机构要求的同意和伦理流程，使用匿名编号；这是具体研究实施事项，不是本次资料收集的审批请求。

## D. 实验型脚手架与撤除：第二阶段

固定一个经教师校验的交互实验，比较纯文本提示、固定实验引导、自适应撤除引导。避免同时比较动画质量、声线、内容难度与提示强度。

教学循环：预测 → 动手 → 观察 → 解释 → 改写 → 新任务。逐步从局部提示降到问题提示，再到无提示。检测熟练度不能只看通过测试，还要看原理解释和新情境。

主结果：无AI实现及概念迁移；工程指标：教具正确率、不可执行率、反馈对实验状态的匹配、延迟和生成成本。Manim生成采用模板/验证后再扩大，不把开放视频生成作为首个系统的关键路径。

## E. 可发布的分支教学评测集

在公开教育基准上补充长会话分支场景，并核对原数据许可。场景包括：有益先修分支、无关分支、回归时忘记原目标、分支矛盾、学生依赖提示答对、改正后复发、拒绝检查、时间紧迫。

任务分开评分：原目标恢复、相关证据检索、掌握诊断、下一动作、答案泄露、对学生绕开行为的处理。为每例提供可审核的目标与证据标注；教师双标并报告分歧。LLM模拟允许压力测试，但公开报告必须明确它不是真人学习研究。

已有LongTutor与多个TutorBench，不能只换题目重新命名。增量要是分支干扰与提示依赖等明确缺失能力，并用真实轨迹检验其生态效度。优先发布可复用任务和注释规范，而非只发布一个汇总分数。

## F. 一条现实的推进路线

- 第1—2周：精读最近邻；访谈；确定一个课程单元、主RQ和主要结果。
- 第3—5周：事件账本、任务/分支状态、轻量界面与固定实验；先让所有条件可切换和可审计。
- 第6—7周：pilot，校验任务难度与诊断策略，做功效分析及预注册。
- 第8周以后：按招募与课程时间实施正式研究并等待延迟测验。

这只是顺序与工期估计，正式样本、伦理审批、教学安排和纵向观察可能明显延长。不要为了赶开发进度省掉延迟测试。
