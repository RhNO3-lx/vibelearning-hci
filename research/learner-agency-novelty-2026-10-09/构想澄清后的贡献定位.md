# 构想澄清后的贡献定位

日期：2026-10-09。本文件补充原查新报告，依据用户新描述修正比较对象；不把建议当作用户已经确定的设计。

## 用户明确的原型

- 左侧展示当前线路的线性对话流；右侧可切换会话交互轨迹图和跨会话知识图。
- 会话图有根，每轮对话一个节点，可分支、切换与标记主线；分叉处存子树摘要。节点关联活动类型与知识节点。
- 知识图边代表先修关系，边权计划表达学习过渡难度。节点含概要、难度、掌握程度、难点，并链接相关交互节点。
- session 开始明确目标、补充知识结构与子目标；Agent 提议路径，用户可直接编辑或请求辅助编辑。
- 用户可主动请求测验来更新掌握判断；每轮结束更新图。

“全局知识图”暂按同一学习者跨 session 的图理解；不推定为全体用户共享个人掌握数据。用户进一步明确：**切换支线后，Agent 默认使用整个 session 的所有支线摘要。**

因此，会话树／摘要树首先承担组织、压缩、追溯与细节定位职责；不以默认上下文隔离或阻止跨分支信息传播为设计目标。与此前查新报告中的作用范围控制候选不同，此版更强调跨分支信息整合及活动证据对教学的价值。

## 调整后的判断

比“多个界面功能的组合”更明确的贡献候选是：**一种关联探索轨迹、记忆摘要与概念掌握证据的联合表征，并让学习者与 Agent 通过相互关联的视图共同管理教学路径。**

这应被理解为同一学习过程的多种结构相互关联，而非将会话树、记忆索引和知识图强制变成一种拓扑。即使交互树和摘要树共享节点标识，概念之间仍需要独立的多对多关系。

最有意义的两个循环是：

1. **面向 Agent 的循环：** 学习活动→具体交互证据→概念状态→相关历史检索与路径调整→下一活动。
2. **面向学习者的循环：** 查看概念状态→定位判断所依据的对话／测验→请求重测或修改路径→观察后续教学及状态变化。

用户已明确第二个循环中的路径编辑和请求重测；直接质疑或编辑证据、控制记忆作用范围等属于可选增强，不应替换用户原设想或被当作必需的唯一研究方向。

## 与最强近邻的实际比较

| 近邻 | 已有重叠 | 需要论证的候选差异 |
|---|---|---|
| [DeepTutor v3](https://arxiv.org/html/2604.26962v3)，§2.1、§3 | 交互痕迹、分层记忆、学习者画像与教学／练习共享更新，跨学习活动复用 | 用户实际探索分支是否同时组织历史检索；概念状态到具体活动证据的可操作追溯；主线／支线与用户编辑如何改变教学 |
| [LOOM](https://arxiv.org/html/2511.21037v1)，Pipeline、Future Plan | 对话形成学习信号、目标—课程图和后续提议；图协商已有未来计划 | 逐轮活动到概念证据的细粒度关联；实际分支操作、概念层掌握与先修路径的协同变化 |
| [MindTrellis](https://arxiv.org/html/2604.23129v1)，§§4–6 | 图中查询与贡献、关系和层级编辑、来源追踪 | 显式区分学习材料来源与学习者能力证据；跨 session 的掌握状态、活动轨迹及教学决策关联 |

这些差异是需要核查、实现与测试的候选，不是已证实的首次贡献。尤其“共享学习者模型并让每次交互改善下一次教学”，DeepTutor 已明确提出，不能以此单独建立 novelty。

## 建议明确的四项更新语义

### 1. 同一知识图中保留不同层的信息

领域层：概念、先修关系、来源、内容概要。个人层：掌握估计、置信度、难点与证据、兴趣和目标。session 层：当前计划、目标集合、活动和分支。

它们可以呈现在同一图中。逻辑区分有助于避免删除某次计划节点就删除长期知识记录，以及把学习者的困难误写成概念的客观属性。

### 2. 每轮记录证据，根据证据类型决定是否更新能力估计

概念讲解可以改变“已接触”；追问可以记录待澄清点；测试产生能力证据；实践产生任务表现证据。状态应允许不确定与冲突。用户自评、Agent 判断和测验记录应可区分，不能将阅读一次回答计作掌握。

调用独立子 agent 出题是实现方式，并不自动保证题目和评分有效。证据还需记录题目难度、目标概念、提示程度、时间和表现，至少保留足够信息解释更新。

### 3. 记忆的保存范围与读取范围分开定义

按照用户选择，默认提供覆盖整个 session 所有支线的摘要；可在此基础上按当前路径与目标检索原始细节。完整覆盖全部支线，不要求同时重复注入每个层级的嵌套摘要。摘要来源需保留原始交互标识，避免同一证据经祖先摘要和子树摘要重复出现后被重复计入掌握更新。摘要预算不足时仍须说明截断或压缩，不能宣称完整保留。

还需明确当前路径的详细上下文、个人状态的跨分支共享，以及返回旧节点时采用的状态版本。上述详细上下文／检索方案是实现建议；用户目前确定的是默认读取全部支线摘要。

知识掌握状态跨 session 更新与原始对话不可变可以同时成立。会话父子关系表示探索来源；概念状态另按证据时间演进，避免返回旧对话时混淆当时状态和当前状态。

### 4. 路径编辑的影响具体可见

从计划移除概念仅表示此时不学；标记主线表示当前优先方向；两者都不代表已经掌握其他节点。新增目标、跳过先修、请求重测后，Agent 应说明建议怎样变化，同时尊重用户明确的路线选择。

先修边和预计过渡成本分别存储。个人的过渡成本可以随知识状态、教学方式、时间预算变化；初期宜用有理由的粗略估计，避免未校准的小数分数伪装为精确预测。若将它作为新算法贡献，需要额外验证预测有效性。

## 贡献与效益应分开陈述

- 设计贡献候选：联合表征、双向追溯、用户与 Agent 的路径共管机制。
- 自适应假设：活动和分支历史比仅有概念掌握分数提供更多有效信息，改善解释与练习匹配。
- 交互假设：双视图关联改善定位、恢复探索与学习监控；在较复杂的分支图中也可能增加负担。
- 教育假设：更好的监控与教学匹配改善无 AI 的解释、迁移或保持。
- 信任假设：用户更能区分可靠判断和不确定判断。应关注信任是否恰当，而不是仅追求更高信任评分。

“更完备”须落实为新增哪些可利用的信息和减少哪些判断错误。“更快”须区分更少澄清轮次、检索成本与系统时延。首篇研究建议选一项主要机制结果和一项主要学习结果，其余作为次要结果，避免同时承诺所有收益。

## 对照建议

可先在相同图式界面下比较“仅概念状态”与“概念状态＋可追溯活动／分支证据”，检验表征信息的增量；也可固定信息与教学能力，比较是否允许用户直接编辑路径，检验交互控制的增量。两个对照分别回答不同问题，不宜混为一项效应。

用户完整构想可以作为最终原型目标。论文选择其中一个机制清楚的切口，并不要求产品永远只做这一项。当前更准确的研究表述是：

> 如何通过关联探索轨迹、记忆摘要与概念掌握证据，使学习者和 Agent 共同维护学习状态与路径？这种关联何时改善教学适应与学习监控，何时引入额外的导航和管理成本？
