# 探索式 AI 学习助手：新颖性核查

核查日期：2026-10-09。对象：可见的探索分支、可解释且可控的 Agent 记忆范围、知识图与可协商学习路径，以及这些控制对自主性、理解和导航负担的影响。

## 1. 结论

**原始方向值得继续，但目前的宽泛表述不足以作为论文的核心新颖性主张。** 树状对话、可操纵的 LLM 记忆、人机共建知识图、开放学习者模型、协商教学与路径调整，均有明确先例。“控制更多是否帮助学习、何时增加负担”也属于已有研究问题。

本轮最影响判断的新增近邻是 **LOOM、Memolet、Memory Sandbox、Mindalogue、MindTrellis，以及开放学习者模型（OLM）研究**。此前只围绕 DeepTutor 和树状 Agent 记忆比较，会高估创新空间。

较有希望的方向是：定义并实现**探索分支中的证据如何进入学习者模型，以及学习者如何理解、协商和纠正这个过程**；再验证这些操作如何改变下一步教学、学习者的独立理解与导航成本。这是一个待验证的增量贡献候选，不是已经证明的空白，也不能仅以“尚未发现完全一样的系统”为依据。

建议暂时把项目定位为 HCI／AIED 交互机制与教育实证研究。树存储和检索可以是实现基础；如要单独主张记忆算法创新，需要另做算法与基准对照。

## 2. 本次核查的范围和证据标准

本轮通过公开网页检索，访问 arXiv 原文、ACL Anthology、出版商页面、作者／实验室页面和官方项目仓库；从 LOOM、OLM、记忆交互和图形探索论文进行参考文献追踪。同时复用本仓库 10 月 3 日与 10 月 7 日的原文核查记录。本轮没有批量新增 PDF，也没有重新逐页阅读所有旧文献。

这是一轮有检索记录的**定向近邻审查**，不是 PRISMA 系统综述，不声称穷尽 ACM、Web of Science、Scopus 或知网数据库。中文检索覆盖较弱；近期预印本、未索引项目、受限全文仍可能改变结论。

对每篇工作区分：已实现机制、作者提出但尚未实现的未来方向、已开展的用户研究、独立学习效果证据，以及仅核实摘要／元数据的部分。具体阅读深度见 [文献目录](文献目录.json)，检索入口和未解决问题见 [检索记录](检索记录.md)。表中的“未核实”不能解释为“没有”。

### 需要特别修正的两处阅读误区

Mindalogue 摘要称减少任务步骤，但 §8.1.1 报告的非线性条件有更多操作与更长探索时间。操作计数在两界面中的定义也不同。该文支持“探索行为和体验改变”的先例判断；不能直接据摘要复述为客观学习提高或效率提高。

LOOM 当前的学习者图主要是目标—课程两层结构，含模块进度；其双向图协商是未来方向。这同时说明：它尚未完整实现我们的候选机制，但已经提出相邻研究议程。实现未来工作可以构成推进，仍须说明更具体的问题、设计与证据贡献。

## 4. 另外四条会压缩创新空间的线索

### 4.1 图形化 LLM 探索

[Sensecape](https://arxiv.org/abs/2305.11483) 和 [Graphologue](https://arxiv.org/abs/2305.11473) 已支持多层探索或通过交互图展开回答。**可视化不是原创性论证的终点**，应比较用户可以做什么，以及这些动作是否改变模型输入和后续教学。

[Branchat](https://doi.org/10.1145/3772363.3798792) 已核实为 CHI EA 2026 树状长期对话回访工作；作者实验室页面提到上下文历史控制。本轮仍未取得论文全文，不能填上其样本量、具体记忆操作或学习效果。它是投稿前必须补全文的近邻。不要与 Devpost 上同名 branchat 原型混为一项。

### 4.2 Agent 记忆算法

[MemTree](https://proceedings.iclr.cc/paper_files/paper/2025/hash/0382cb76309820f71c6eacd47b36ce71-Abstract-Conference.html)、[H-MEM](https://aclanthology.org/2026.eacl-long.15/)、[MAGE](https://arxiv.org/abs/2606.06090)、[Weighted Memory Tree](https://arxiv.org/abs/2608.20631)、[MemForest](https://arxiv.org/abs/2605.23986) 和 [SegTreeMem](https://arxiv.org/abs/2606.04555) 已用不同层级或树组织语义、执行状态、时间与重要性。**树状 Agent 记忆不能单独构成算法创新。** 它们组织的对象并不相同，不能因名字包含 tree 就判定完全覆盖，也不能因不是教育任务就忽略其方法先例。

[Knoll](https://arxiv.org/html/2505.19335v1) 进一步实现用户建立、配置、共享知识模块，并显示模型使用的模块；有公开部署。知识模块可控与输入来源可见也不是空白。

### 4.3 已有自适应 tutor

[DeepTutor 论文](https://arxiv.org/abs/2604.26962) 的 TraceForest、学习者画像与教学规划，以及 [ScaffoldLM](https://aclanthology.org/2026.acl-long.325/) 的评估驱动记忆、[CoLearn](https://arxiv.org/abs/2609.21154) 的学习者状态和误解建模，都是自适应记忆的近邻。

DeepTutor 论文版本与当前软件必须分开比较。本轮[官方仓库](https://github.com/HKUDS/DeepTutor)显示 2026-10-08 的 v1.6.14；README 还描述三层 Memory、Mastery Path 与 Partner 对话 branch／resume。**不能写 DeepTutor 没有分支或没有记忆工作台。** 本轮没有运行该项目或完整审计源码；分支是否具有我们拟研究的学习证据与协商语义，尚未核实。

[LearnerCoMPASS](https://aclanthology.org/2026.acl-long.408/) 已结合知识图、认知诊断和自适应路径搜索。原文 §4 与附录 A.6 的人类评估主要评定生成路径；预测效率、可持续性不是学生实际完成课程后的保持／迁移成绩。其 MCTS 搜索分支不是用户可操作的对话分支。

### 4.4 教育控制权与导航代价

[Amadieu 等](https://doi.org/10.1016/j.learninstruc.2009.02.005) 已研究先验知识、概念图结构、迷失、负荷和学习之间的关系；[超文本负荷综述](https://doi.org/10.1016/j.chb.2005.08.012)也提供历史背景。两项本轮沿用原始摘要／预览，未补全文。

[概念图元分析](https://doi.org/10.1007/s10648-017-9403-9)可支持知识表征研究的背景，但不能把其效应量移植给分支聊天。[学习路径控制实验](https://www.frontiersin.org/journals/psychology/articles/10.3389/fpsyg.2022.973758/full)也说明控制权、学习耗时与结果需共同考察。先验知识和任务复杂度是合理的候选边界条件，却不是本项目首次发现的问题。

## 5. 哪些主张不能用，哪些仍可尝试

| 拟写主张 | 判定 | 更稳妥的改写 |
|---|---|---|
| 首次用树状聊天支持学习探索 | 不成立 | 在已有非线性探索研究上，研究某种具体的学习状态／证据控制机制 |
| 首次提供可解释、可编辑 Agent 记忆 | 不成立 | 明确定义分支记忆控制对教学决策的作用，并核查用户能否理解这种作用 |
| 首次让学习者与 AI 共建知识图 | 不成立 | 区分知识图编辑、学习者自评、能力证据与教学规划，研究它们之间的可协商转换 |
| 首次实现图上的自主学习路径选择 | 不成立 | 给出接受、拒绝、替代路线、目标改变时可观察的重规划规则 |
| 首次研究自主性和导航负担的权衡 | 不成立 | 在特定控制对象和学习任务中识别效应及条件，而不是重提宽泛权衡 |
| 首次把所有功能组合起来 | 尚未证实，也偏弱 | 说明组合产生了怎样的交互／推断问题，并验证解决方法 |
| 分支证据控制改善教学匹配与独立理解 | 可研究，结果未知 | 提出机制和可证伪假设，允许结果显示收益有限或负担增加 |

知识图、会话树、记忆索引、学习者模型应是四个可关联但不同的对象。会话节点可以关联多个概念，概念可以跨分支连接；模型记忆不宜被界面树强行限制为纯树。将它们区分开有助于清楚界定控制作用，但这种区分本身也不是已经证明的新算法。

## 6. 建议收窄后的贡献候选

推荐先围绕这个问题做原型与研究：

> 在多分支学习探索中，学习者如何理解和协商“这段交互应影响哪些后续回答、能力判断和学习建议”？显式控制这些影响，能否减少错误的学习状态推断，并支持更有效的探索与回归？

相较于原问题，这一表述把控制对象落实到**交互证据的用途与影响范围**。仍需与 Memolet 的上下文操纵、OLM 的证据质疑、LOOM 的图更新愿景直接比较。

一个可测试机制可以包含以下操作：

1. **创建探索支线。** 用户可以说明这是暂时假设、旁支兴趣或当前学习目标；界面展示实际参与当前回答的记忆来源。仅折叠节点不应被误认为停止使用该信息。
2. **区分信息与能力证据。** “Agent 解释过”“用户说懂了”“用户独立解答过”采用不同记录类型。一次对话或用户点击“保存”不自动变成已掌握。
3. **协商跨分支影响。** 用户可让一段信息参与指定回答／其他支线，或阻止某条临时假设被写为全局判断。若用户与 Agent 对掌握程度不同意，保留两种判断和各自依据。
4. **让选择产生教学后果。** 显示路径建议基于哪些目标和证据；用户修改后系统实际重算候选路线。解释“为什么变化”与“为什么没变”。允许纠正掌握判断，但不把自评直接当作经验证的掌握。
5. **支持探索后的整合。** 回到主问题时，由学习者选择相关发现，做解释、比较或迁移小任务；Agent 据新增证据更新模型，而不只生成一份合并摘要。

这些动作分别有先例。潜在贡献在于一致的操作语义、它们之间的教育机制及受控验证。实现时必须记录实际检索／注入、模型更新和规划事件，才能检查控制是否生效；界面承诺不能替代行为证据。

例如，学习 SQL 时，从 JOIN 主线转去探究集合与多重集。用户在支线提出一个错误假设，它可以被保留为待检验观点，但不能被记录成用户掌握的知识。回到 JOIN 后，用户决定引入支线结果；Agent 依据一次独立解释任务判断需不需要补充练习，并让用户选择继续 JOIN 或先补多重集。这个闭环比“增加一个分支按钮”更能说明研究对象。

## 7. 怎样验证，才有机会形成论文贡献

首篇论文不建议同时验证新记忆算法、三种界面、全面课程规划和长期学习。先固定一个领域、知识图、分支 UI 与教学策略，对**自动更新与显式协商更新**做比较，可以更清楚地识别所提机制的影响。之后才增加线性／树状界面条件或做机制消融。

强基线也应有相同的模型、课程内容、评估支持、图和路径推荐能力；仅改变研究中的控制机制。不能用一个没有记忆和教学支持的裸聊天系统比较整套系统，然后把差异归因于树状记忆。

建议将结果分为四类：

- **控制是否可理解、是否真正生效：** 用户预测某条信息在哪些分支会生效的正确率；系统接受／拒绝和撤回操作后的行为一致性；错误的全局能力推断与纠正次数。
- **学习者自主性：** 目标与路线的主动调整、对理由的质疑、选择后的实际行动；配合有依据的主观测量。点击数、分支数不是自主性的充分指标。
- **独立理解：** 前测、无 AI 的解释与迁移任务、延迟测验；区分有工具时完成任务和离开工具后学会。
- **成本与边界：** 导航、恢复上下文、记忆管理用时及工作负荷；记录学习时间。先验知识优先作为一个预先指定的调节因素，避免小样本同时检验大量交互效应。

先用形成性研究确认用户是否遇到“探索观点误入学习者模型”“不知道某支线影响了什么”等实际问题。随后根据主要结果指标做样本量设计，预先明确假设和分析。若负担增加或学习没有改善，这仍可能提供有价值的设计边界；但需要可信机制和充分证据，不能以“负结果也能发”替代研究质量。
