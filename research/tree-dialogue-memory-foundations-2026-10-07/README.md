## 阅读与版本说明

T04（辅导提问）、T07（超文本负荷综述）、T08（先知识×概念图）没有取得全文，只按原始摘要/预览分析。T10的本地PDF是1993技术报告，相关1995期刊稿未取得，明确分别标注。D04为276页博士论文，只重点核查架构与话语树章节，未声称全篇精读；原PDF字符命名已在提取文本中解码并与PDF211页视觉核对。

MemTree已有ICLR2025发表版；H-MEM使用EACL2026发表版；其他近期预印本不冒称已同行评审。官方仓库网页说明已核查，但API限流/Git连接失败，未保存固定commit快照，未运行代码。

结论：教育证据支持“层级、联系、回返与有价值的提问”，不证明“思维本质为树”。树状记忆和树状对话确有现成研究；它们的父子关系、检索范围和验证对象不同，不能合并为一个已验证的教学机制。
