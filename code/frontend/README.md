# Vibe Learning 前端

一个以对话为主、以探索树和知识图为路标的学习工作台。代码位于 `code/frontend`，后端按项目规划另行接入。

## 启动

需要 Node.js 22.12+、24+ 或 26+（当前开发环境为 Node 26）。

```sh
cd code/frontend
npm ci
npm run dev
```

浏览器打开 http://127.0.0.1:5173 。服务仅绑定本机。端口被占用时会明确报错，可停止已有实例或用 `npm run dev -- --port 5175`。

```sh
npm run build       # 类型检查并构建生产文件
npm run preview     # 预览 dist
npm test            # 状态与持久化不变量测试
npm run typecheck
```

## 可以实际操作的流程

- **会话**：目标引导、新建/切换；侧栏会话右键重命名、设置独立工作区、删除。设置中的默认工作区仅供新会话继承。
- **对话**：Markdown 和公式、上下文占用估算、附件选择/拖放/图片粘贴、活动选择、资料与能力绑定、⌘/Ctrl+Enter 发送。
- **分叉**：划词追问、回答旁分叉、节点详情创建分支；一轮问答一个节点；返回祖先路径；主线标记；删除子树及其演示证据。
- **学习卡片**：单选诊断反馈、闪卡翻面与自评、项目实践清单。提交一次不会重复增加证据，闪卡自评不计入掌握分数。
- **两张图**：拖动/缩放/适应全图、切换/并看、紫色探索树与蓝色知识图独立选中；树节点相关模块紫色外发光并缓动框选全部关联、模块详情、展开知识点、关联对话回访、发起诊断分支。
- **路线**：模块加入/移出、记录原因、上下移动；咨询学习伙伴生成当前节点的孩子；全局删除模块移除所有路线关联，保留历史证据。
- **布局**：右侧分隔条拖动调整地图宽度，并看时可上下调整两图高度；支持方向键与 Home 复位。地图开关只在右侧，收起后保留展开入口。地图可从标题栏拖出或点击浮动按钮；浮动后拖到最右侧吸附，或点吸附按钮。小屏地图为可收起覆盖面板。
- **配置**：知识库与资料登记、Agent 命令配置、技能指引、启停、会话能力选择、学习偏好、数据导出与重置。

图初始聚焦当前节点/相关模块，让文字可读。左下角“适应全图”可查看全部节点；并看视图将空间留给两图，详情在各自单图标签查看。

## 演示与真实能力的边界

当前使用 `src/seed.ts` 的预设演示数据和纯函数 `demoTurn`，**未连接模型或 Flask**。界面标记演示模式，普通追问返回明确的演示内容；有限模块有固定题，自定义模块不会编造诊断证据。

参考分是演示状态，不是校准的掌握概率。初始部分模块的分数用于展示 UI；新演示测验按有效作答的正确比例展示参考分。不会因为 Agent 讲解或闪卡自评而增加能力证据。

摘要版本、接收游标、替代和撤回记录用于验证交互。没有生产级摘要抽取、全文检索、模型 token 计算或上下文压缩；真实记忆引擎在后端阶段实现。

知识图是带来源入口的演示种子图；边只保留先修类型，预估难度属于节点。旧记录中的有帮助边会移除，先修边清除旧置信度、帮助程度和来源属性；会话、摘要记录与节点信息保留。当前不声称已完成可靠自动建图。

后续 Flask/SQLite 应遵循 `code/contracts/knowledge-graph.schema.json`：节点含 `difficulty`，边仅含 `id/source/target/type`，`type` 固定为 `prerequisite`。本轮提供共享契约，尚无应用后端可迁移数据库。

附件仅在当前运行期供图片预览；刷新后保留名称/大小/类型，并提示重新添加预览。知识库导入仅登记这些元数据，未解析/索引或上传正文。前端不会访问设置中的本地路径、运行命令或启动外部 Agent。

所有会话及配置保存在此浏览器的 `vibelearning.frontend.v1` localStorage；损坏状态回退为种子数据。API Key 仅在设置页面状态中暂存，不写入 localStorage、不发送、不出现在导出中。其他保存数据可能包含用户填写的学习内容，应使用合适的浏览器环境。

## 代码结构

| 文件 | 职责 |
|---|---|
| `src/App.tsx` | 工作台、输入、对话、模态框与导航 |
| `src/model.ts` | 领域类型、树操作、学习证据、路线和摘要同步 |
| `src/seed.ts` | 种子数据、新会话与演示回复适配函数 |
| `src/storage.ts` | 本地序列化校验与恢复 |
| `src/components/GraphPanel.tsx` | React Flow 两图、聚焦、详情、浮动面板内容 |
| `src/components/Cards.tsx` | 测验/闪卡/项目卡片 |
| `src/components/ConfigPages.tsx` | 五类配置页及本地导出 |
| `src/model.test.ts` | 树、同步、证据、路线、恢复不变量 |

后端可替换演示回复函数，将服务事件映射到现有类型；需要另外实现真实流式消息、工具调用、文件/知识库解析、全局学习者模型和沙盒。用户交互与消息事件协议应在后端阶段定稿，当前不是已验证的生产 API。

类型检查、生产构建和 23 项 Vitest 测试；浏览器实际验证包括划词分支、发送/刷新、知识图诊断与证据更新、路线排序与原因、浮动拖拽吸附、资源与能力配置、图片粘贴和 390px 窄屏。
